# Assignment 2 - E-Kart.co Website

This project is a responsive web application built using HTML5, CSS3, and Bootstrap.

## Features
- **Navbar**: Navigation links for Home, Quick links, and Contact.
- **Hero Section**: Gradient text effect with call-to-action button and search input.
- **Responsive Design**: Designed to fit various screen sizes using Bootstrap and CSS.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Linear Gradients)
- Bootstrap 5
