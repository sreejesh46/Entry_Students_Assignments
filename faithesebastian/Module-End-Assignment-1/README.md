Objective:
The purpose of this assignment is to evaluate a complete understanding of
HTML5 semantic structure, CSS layouts using Flexbox and Bootstrap,
responsive design, and visual styling by building the fully polished ShopNest
e-commerce website — the visual foundation that will be converted to React
in Phase 3.

Assignment: Build a complete static ShopNest e-commerce website using
HTML5, CSS, Flexbox, and Bootstrap.

Requirements:
● Use a correct HTML5 boilerplate with all semantic tags: header, nav,
main, section, article, aside, and footer.
● Create a sticky navigation bar with the ShopNest logo, navigation links, a
search bar placeholder, and a cart icon.
● Build a full-width hero banner with a background image placeholder,
headline, subheadline, and two CTA buttons — 'Shop Now' and 'View
Deals'.
● Build a Featured Products section with at least 6 product cards — each
with image, name, original price (strikethrough), discounted price, star
rating, and an 'Add to Cart' button.
● Add a Category Showcase section displaying at least 4 categories as
clickable visual tiles (Electronics, Clothing, Footwear, Books).
● Add a newsletter signup section and a multi-column footer with About,
Quick Links, Contact, and Social Media columns.
● Make the entire page fully responsive using Flexbox, Bootstrap Grid, and
media queries for mobile, tablet, and desktop breakpoints.
