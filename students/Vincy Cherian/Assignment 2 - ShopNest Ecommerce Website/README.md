# 🛍️ ShopNest – E-Commerce Website

ShopNest is a static e-commerce website created as part of my MERN Stack development class assignment.

The website is designed to provide a clean, modern and responsive shopping experience with featured products, product categories, promotional banners, newsletter signup and footer sections.

## 🚀 Features

- Responsive navigation bar
- ShopNest logo and branding
- Sticky navigation bar
- Search bar
- Shopping cart icon
- Hero carousel with promotional banners
- Shop Now and View Deals CTA buttons
- Featured Products section
- Product cards with:
  - Product image
  - Product name
  - Original price
  - Discounted price
  - Star rating
  - Add to Cart button
- Browse by Category section
- Newsletter signup section
- Multi-column footer
- About ShopNest section
- Quick Links
- Contact information
- Social media links
- Responsive layout for mobile, tablet and desktop screens
- Login modal using Bootstrap

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- Flexbox
- CSS Media Queries
- Google Fonts
