# Alankar Jewellery Website

A modern, elegant jewellery brand landing page built using **HTML, CSS, and Bootstrap**.
This project was created as a **vibe-coding / frontend practice project** for the fictional jewellery brand **Alankar**, focusing on luxury aesthetics, responsive design, and curated product presentation.

---

## ✨ Project Overview

**Alankar Jewellery** showcases timeless jewellery collections through a premium single-page website experience. The design emphasizes warm luxury tones, clean typography, high-quality product imagery, and smooth section-based navigation.

### Included sections

* Hero banner
* Sticky navigation bar
* Best Sellers & New Arrivals catalog
* Browse by Category section
* About section
* Store details
* Contact information
* Responsive footer
