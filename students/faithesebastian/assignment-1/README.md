# Objective:

# The purpose of this assignment is to test your understanding of HTML5

# document structure, semantic tags, CSS styling, and the box model — core

# skills covered in Sessions 4 to 6 — by building a visually styled restaurant

# menu page.

# 

# Assignment: Create a restaurant menu page using HTML5 and CSS.

# 

# Requirements:

# ● Use proper HTML5 boilerplate with <!DOCTYPE html>, <html>, <head>,

# and <body> tags — include a meaningful <title> and charset meta tag.

# navigation bar with links: Menu, About, and Contact.

# ● Create at least 3 menu category sections (e.g. Starters, Main Course,

# Desserts) — each with a section heading and at least 3 menu items.

# ● Each menu item must include a name, short description, and price —

# style each item as a card using padding, margin, and border.

# ● Add an 'About Us' section with a short paragraph about the restaurant

# and its story.

# ● Include a footer with the restaurant address, opening hours, and

# copyright text.

# ● Apply CSS styling using selectors, hex/RGB colors, Google Fonts

# typography, text-align, line-height, and box model properties
